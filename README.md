# BMS Explorer

Interactive EV Battery Management System explorer -- SOC/SOH/SOP estimation (incl. AI methods), battery chemistry, IGBT vs MOSFET, TVS vs MOV, HV contactor + precharge, MCU/AFE/sensor architecture, thermal management, control firmware, DC-link/losses, standards & testing, and a live 14S2P BMS simulator.
